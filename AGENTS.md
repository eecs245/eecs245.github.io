# Website Agent Notes

- In `_modules/week-*.md`, lab and homework titles should be bolded only after release.
- Treat a lab or homework as released when its schedule event has the released assignment link, usually `problems:`, or when the user explicitly says it has been released.
- Released lab/homework titles should use `<b>...</b>` in `title:`. Unreleased lab/homework titles should be plain text with no `<b>`, `<strong>`, or Markdown bold.
- Homework events use `type: hw`; do not change them to `type: homework`.
